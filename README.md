# Focus Flow - Task Manager

## Description
Focus Flow is a simple task management web application with a built-in Pomodoro timer. It helps students and busy individuals stay organized and focused by combining task tracking with time management in one tool.

## Features
- ✅ Add, Edit, Delete Tasks
- ✅ Mark Tasks as Complete
- ✅ Filter Tasks (All, Active, Completed)
- ✅ Sort Tasks (By Date, By Priority)
- ✅ Pomodoro Timer (25 min work / 5 min break)
- ✅ Local Storage (tasks persist between sessions)
- ✅ Responsive Design (works on mobile and desktop)
- ✅ Input Validation
- 
## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Start adding tasks!
